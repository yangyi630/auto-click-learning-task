# 学习任务自动完成工具

## 功能介绍

本工具用于自动完成学校安排的学习任务，支持以下功能：
- 自动打开学习页面
- 自动识别并执行任务列表
- 根据任务说明自动执行点击操作
- 支持虚拟机操作任务
- 自动生成实验报告

## 环境要求

- Python 3.8+
- Chrome 浏览器
- 校内网络环境

## 安装步骤

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行程序：
```bash
python main.py
```

## 使用说明

1. 确保已连接校内网络
2. 运行程序后，点击"一键运行"按钮
3. 程序会自动打开浏览器并执行所有任务
4. 任务完成后会自动生成实验报告
5. 报告保存在 `reports` 目录下

## 项目结构

```
.
├── config.ini          # 配置文件
├── main.py             # 主程序入口
├── requirements.txt    # 依赖列表
├── modules/
│   ├── automation.py   # 自动化点击模块
│   ├── gui.py          # GUI界面模块
│   └── report_generator.py  # 实验报告生成模块
├── templates/          # 模板目录
└── reports/            # 报告保存目录
```

## 注意事项

1. 本工具仅供学习参考使用
2. 使用前请确保已阅读并遵守学校相关规定
3. 建议在使用前备份重要数据
4. 如遇页面结构变化，可能需要更新自动化逻辑
