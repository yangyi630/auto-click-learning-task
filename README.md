# 自动点击展开运行学习任务（auto-click-learning-task）

自动点击展开运行学习任务的 Python 自动化工具（基于 Selenium）。

## 简介

用于自动点击、展开并运行学习任务的自动化脚本，适配 Chrome / Edge 浏览器。

## 目录结构

- `try/`：应用源码（`main.py`、`modules/`、`templates/`、`config.ini` 等）
- `自动点击展开运行学习任务_简历项目简介.txt`：项目简介

## 说明

- `config.ini` 仅含 url / 浏览器 / 超时等配置，无账号密码，可安全使用。
- 依赖与临时目录已通过 `.gitignore` 排除。
